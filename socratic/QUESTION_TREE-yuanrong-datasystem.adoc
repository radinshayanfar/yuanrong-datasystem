== Q1: What problem does this bounded context solve, and for whom?

=== Q1.1: Product identity — what is this bounded context?
[ANSWERED]
Evidence: README_EN.md:34, include/datasystem/datasystem.h:33, src/datasystem/worker/worker_main.cpp:52
openYuanrong DataSystem is a distributed multi-level (DRAM/SSD, plus device HBM)
caching system for compute clusters. It ships as an SDK (`DsClient`) linked into
user processes and a per-node `datasystem_worker` runtime process; the two halves
are the poles of the same context.

=== Q1.2: Who are the primary users?
==== Q1.2.1: What API personas does the code expose to application developers?
[ANSWERED]
Evidence: include/datasystem/kv_client.h:75, include/datasystem/object_client.h:53, include/datasystem/stream_client.h:42, include/datasystem/hetero_client.h:45
Application developers integrate one of four client families: `KVClient`
(key/value), `ObjectClient` (reference-counted shared-memory objects),
`StreamClient` (producer/consumer pub-sub), and `HeteroClient` (NPU/GPU device
memory). These are the direct in-process users of the context.

==== Q1.2.2: What operator/deployer persona does the code expose?
[ANSWERED]
Evidence: cli/command.py:1, cli/start.py:1, cli/stop.py:1, README_EN.md:153
A cluster operator drives deployment through the `dscli` CLI (`start`, `stop`,
`up`, `down`, `generate_helm_chart`), targeting worker + ETCD topology.

=== Q1.3: Through what channels is the product delivered/consumed?

== Q2: What is the specification of this bounded context?

=== Q2.1: Who/what are the actors?
==== Q2.1.1: SDK application process (primary human-driven actor)
[ANSWERED]
Evidence: src/datasystem/client/datasystem.cpp:26, include/datasystem/utils/connection.h:27
An application process constructs a client with `ConnectOptions{host,port}` and

==== Q2.1.2: Worker process (system actor / peer)
[ANSWERED]
Evidence: src/datasystem/worker/worker.cpp:245, src/datasystem/worker/worker_oc_server.h:569
Each node runs a worker that serves SDK requests and acts as a peer to other

[ANSWERED]

One node is elected master; it owns metadata/coordination. It is not a separate

`etcdCM_->IsCurrentNodeMaster()` is true.

==== Q2.1.4: ETCD (external coordination actor)
[ANSWERED]
